# 达尔文进化岛 · 需求文档（PRD）

> 版本：v1.0　｜　平台：Unity 3D　｜　类型：单人 / 俯视 / 打怪进化生存

---

## 1. 概述

一款单人 3D 俯视角生存游戏。玩家在一座遍布野生动物（怪物）的孤岛上，**自动攻击**
四周的敌人，靠击杀获取经验、不断**进化**成更强大的形态，目标是尽可能存活更久、
进化到更高阶。核心爽点：操作极简（只管走位）、越打越强、形态越变越猛。

参考体验：达尔文进化岛 / 弓箭传说式的「走位 + 自动攻击 + 成长」休闲动作玩法。

---

## 2. 目标与非目标

**目标**
- 操作足够简单：玩家只需控制移动，战斗自动进行。
- 战斗有正反馈循环：击杀 → 经验 → 升级/进化 → 更强 → 打更强的怪。
- 敌人有差异化：至少有近战与远程两类不同行为的动物。
- 3D 表现：角色、敌人、场景为 3D。

**非目标（首版不做）**
- 多人 / 联网。
- 复杂剧情、对话、任务系统。
- 复杂经济 / 商店 / 内购。

---

## 3. 平台与技术

- 引擎：Unity（建议 2021 LTS 或更新）。
- 视角：3D 俯视 / 3/4 斜俯视，相机跟随玩家。
- 输入：键盘（方向键 / WASD）；后续可扩展手柄、移动端虚拟摇杆。
- 渲染管线：Built-in 或 URP 均可。
- 美术：首版用程序化基础几何体拼装（无需外部模型资源）；后续可替换为正式美术模型。

---

## 4. 核心玩法循环

```
进入孤岛 → 走位躲避 → 自动攻击最近敌人 → 击杀获得经验
   → 升级 / 进化（变强、形态升级）→ 面对更强的怪 → ……直到阵亡 → 重开
```

---

## 5. 操作需求

| 操作 | 输入 | 说明 |
| --- | --- | --- |
| 移动 | 方向键 或 W A S D | 控制上下左右，在岛上自由走位 |
| 攻击 | 无（自动） | 系统自动锁定并攻击范围内最近的敌人 |
| 重新开始 | R 键 / 点击按钮 | 阵亡后立即重开一局 |

- 要求：操作越简单越好，新手无需学习，拿起即玩。
- 移动需限制在岛屿范围内（不能走进海里 / 掉出地图）。

---

## 6. 玩家角色需求

- 拥有属性：生命值（HP）、移动速度、攻击力、攻击范围、攻击间隔（冷却）。
- **自动攻击**：每隔「攻击间隔」自动选取范围内**最近**的敌人发起攻击（首版为远程弹丸）。
- 受击：被敌人攻击或弹丸命中时扣 HP；可有短暂无敌帧避免瞬间连扣。
- 死亡：HP 归零进入「游戏结束」。
- 朝向：移动 / 攻击时面向对应方向。
- 反馈：受击闪烁、攻击动作、移动时轻微起伏等基本表现。

---

## 7. 敌人需求（重点：两种攻击方式）

通用：敌人有 HP、移动速度、攻击力、攻击间隔、经验奖励；头顶显示血条；死亡有击杀反馈。

### 7.1 近战动物（如野猪）
- 行为：发现玩家后**持续冲向玩家**。
- 攻击：进入贴身范围后，按冷却对玩家造成接触伤害。
- 定位：高威胁、需要玩家不断拉开距离走位。

### 7.2 远程动物（如喷射蛙）
- 行为：与玩家保持一个「理想距离」——太远则靠近，太近则后退（放风筝）。
- 攻击：在射程内按冷却**发射弹丸**攻击玩家；弹丸命中扣血。
- 定位：迫使玩家在躲近战的同时也要躲弹幕。

### 7.3 刷怪规则
- 在玩家周围一定距离外、岛屿范围内持续生成敌人。
- 同屏敌人数量有上限，随玩家等级提升而提高。
- 敌人强度（HP / 攻击）随玩家等级缩放，保持挑战性。
- 近战 / 远程按一定比例混合出现。

---

## 8. 成长与进化需求

- **经验与等级**：击杀获得经验，累计达到阈值则升级；升级提升属性（如攻击、上限 HP），并回血。
- **进化**：达到特定等级时进化为新形态——
  - 外观明显变化（体型 / 造型升级）。
  - 属性大幅提升（HP、攻击、攻击方式可升级）。
  - 进化瞬间回满血并有短暂无敌 + 视觉特效。
- 进化链（建议，可调整）：
  `史莱姆 → 蜥蜴 → 影狼 → 岩石巨兽 → 烈焰翼龙 → 远古巨龙`
  （近战形态可在高阶解锁远程喷吐等更强攻击方式。）

---

## 9. 场景需求

- 一座圆形孤岛，四周是海，岛上有草地。
- 岛上散布装饰物（树木、岩石）增强 3D 表现与层次。
- 玩家与敌人均被限制在岛屿可行走范围内。

---

## 10. UI / HUD 需求

- 顶部 / 角落显示：当前等级、击杀数、HP 条、经验条、当前进化形态名称。
- 敌人头顶：受伤后显示血条。
- 战斗飘字：伤害数字、获得经验、升级 / 进化提示。
- 开始界面：标题 + 玩法说明 + 「开始游戏」。
- 结束界面：本局战绩（进化阶段 / 等级 / 击杀）+ 「再来一局」。

---

## 11. 音效需求（可后置）

- 攻击 / 命中 / 击杀 / 受击 / 升级 / 进化 / 阵亡 等基础音效占位。
- 背景循环音乐。

---

## 12. 游戏状态机

```
开始界面 → 游戏进行中 → 游戏结束 → (重开) → 游戏进行中
```

---

## 13. 验收标准（首版 Done 的定义）

1. 在 Unity 编辑器按 Play 能正常进入游戏并流畅运行。
2. 方向键 / WASD 能控制角色在岛上移动，且不会走出岛。
3. 玩家能自动攻击最近的敌人并将其击杀。
4. 场上同时存在**近战**与**远程**两类敌人，且行为符合 7.1 / 7.2。
5. 击杀能获得经验、升级，并能触发至少一次**进化**（外观 + 属性变化）。
6. HP 归零进入结束界面，可一键重开。
7. 角色、敌人、场景均为 3D 呈现。

---

## 14. 后续扩展（Roadmap，非首版必须）

- 更多动物种类、精英怪、阶段性 BOSS。
- 技能 / 装备 / 天赋等构筑系统。
- 掉落与拾取（经验球、道具）。
- 受击 / 击杀 / 进化的特效与音效完善。
- 用正式美术模型与动画替换程序化模型。
- 移动端适配（虚拟摇杆）、手柄支持。
- 最高分 / 最高进化阶段存档。
